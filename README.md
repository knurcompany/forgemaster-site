# Промо-сторінка ForgeMaster

Односторінковий сайт гри. Чистий HTML, CSS і JS — **без збірки**:
ні npm, ні webpack, ні кроку компіляції. Файли кладуться на хостинг як є.

```
site/
├── index.html
├── assets/
│   ├── css/styles.css
│   ├── js/app.js
│   ├── icons/          ← 29 SVG, скопійовані з project/assets/icons
│   └── shots/          ← сюди класти скріншоти (поки порожньо)
├── _headers            ← заголовки безпеки: Netlify, Cloudflare Pages
├── .htaccess           ← ті самі заголовки для Apache
└── robots.txt
```

## Подивитися локально

Просто відкрити `index.html` подвійним кліком — працює, але браузер
рахує такий файл окремим походженням, і CSP поводиться суворіше, ніж
на справжньому хостингу. Ближче до бойових умов — підняти сервер:

```powershell
cd D:\Claude.file\ForgeMaster\site
python -m http.server 8080
```

Далі `http://localhost:8080`.

## Чого бракує: скріншотів

`assets/shots/` порожня, і сторінка це переживає — замість поламаних
картинок у рамці телефона малюється підпис. Але з реальними знімками
вона стане вдесятеро переконливішою.

Потрібні чотири файли, по одному на вкладку:

| Файл | Вкладка |
|---|---|
| `assets/shots/forge.png` | Кузня |
| `assets/shots/orders.png` | Замовлення |
| `assets/shots/resources.png` | Ресурси |
| `assets/shots/shop.png` | Крамниця |

Знімати вже є чим — `tools/ShotTall.tscn` робить кадр у телефонній
роздільності (на ПК вікно не буває таким високим, тому інакше не вийде):

```powershell
cd D:\Claude.file\ForgeMaster
.\.claude\gd.ps1 tall
```

Вкладка й стан вибираються ключами `ShotTall`: `--size=720x1600`,
`--tab=`, `--zone=`, `--fresh`, `--npc=`, `--anim=`. Знятий кадр
перейменувати за таблицею вище й покласти в `assets/shots/`.

Розмір під рамку — **360×800** або кратний (720×1600 підійде прямо).
Перед заливкою варто прогнати через стиснення, бо PNG з гри важкий:

```powershell
# у WebP, якщо є ffmpeg (він стоїть у C:\Users\sowti\tools\ffmpeg\bin)
ffmpeg -i forge.png -q:v 80 forge.webp
```

Якщо переходиш на `.webp` — поміняти розширення в `index.html`
(чотири рядки з `data-shot`).

Ще один файл згадується в мета-тегах: `assets/shots/og-cover.png` —
картинка для попереднього перегляду в месенджерах, 1200×630.
Без неї посилання просто покажеться без обкладинки.

## Куди заливати

Сайт статичний, тож підійде будь-що безкоштовне:

- **Cloudflare Pages** або **Netlify** — самі підхоплять `_headers`.
- **GitHub Pages** — працює, але **заголовки з `_headers` ігнорує**;
  лишиться тільки CSP із мета-тега в `index.html`. Для промо-сторінки
  це прийнятно, просто знай про різницю.
- Звичайний хостинг з Apache — працює `.htaccess`.

## Що зроблено для безпеки

Сторінка не приймає вводу й нікуди не ходить по мережу, тож поверхня
атаки мала за задумом. Що закрито понад це:

- **CSP без `'unsafe-inline'`.** Ні атрибутів `onclick`, ні `<style>`
  всередині розмітки — усе винесено у файли. Тому політику вдалося
  зробити суворою, а не декоративною.
- **Жодного `innerHTML`.** У `app.js` текст ставиться лише через
  `textContent`, вузли — через `createElement`. Навіть якщо в підпис
  колись потрапить чужий рядок, він лишиться текстом.
- **`form-action 'none'`, `base-uri 'none'`, `object-src 'none'`** —
  форм тут немає, і якщо хтось зуміє вставити свою, надіслати її
  нікуди.
- **`frame-ancestors 'none'`** плюс `X-Frame-Options` для старих
  браузерів — сторінку не вбудувати в чужий фрейм.
- **`nosniff`** — браузер не вгадуватиме тип файлу всупереч заголовку.
- **`rel="noopener noreferrer"`** на всіх зовнішніх посиланнях.
- **`.htaccess` не віддає** `.md`, `.bat`, `.godot` і крапкові файли.

Перевірити після заливки: <https://securityheaders.com> — з цими
файлами виходить A або A+.

## Дрібниці, про які варто знати

- **Палітра не вигадана.** Кольори в `styles.css` узяті з
  `project/scripts/GameData.gd`, де вони лежать як `Color(r, g, b)`
  для руд і зливків. Міняєш метал у грі — онови й тут, інакше
  сайт і гра розійдуться.
- **Іконки — копії.** `assets/icons/` продубльовано з
  `project/assets/icons/`. Оновив іконку в грі — скопіюй сюди.
- **Сторінка тільки темна.** Це свідомо: гра про вугілля й розжарене
  залізо, світла тема виглядала б чужою.
- **Шрифти тягнуться з Google Fonts** і мають кирилицю (Playfair
  Display, Manrope). Якщо треба повна автономність — завантажити
  `.woff2` у `assets/fonts/`, підключити через `@font-face` і
  прибрати `fonts.googleapis.com` з CSP.
